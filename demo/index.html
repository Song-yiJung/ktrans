Werther in colonial Korea베르터, 1923–1932

In what form did Werther appear in colonial Korea, through which languages did it reach Korean, and how do later scholars judge those translations? These are the answers from the UeDeKo bibliography and critical essay, converted into RDF. Every figure below is a SPARQL result on ktrans-data.ttl.

일제강점기에 『젊은 베르터의 고뇌』는 어떤 형태로 실렸고, 무엇을 거쳐 한국어가 되었으며, 후대 연구자들은 그 번역들을 어떻게 평가하는가. UeDeKo의 서지 표와 번역비평 줄글을 RDF로 옮긴 데이터에 이 질문을 던진 결과입니다.

5translations · 일제강점기 번역
64critical statements · 비평 진술
Kim Dong-so, Kim Mi-ji, Lee Yu-yeong, Jo Hyangspeakers · 진술 주체 (김동소·김미지·이유영·조향)
12,199triples queried · 트리플

The judges are later scholars. All evaluations come from present-day scholarship: the UeDeKo critical essay by Jo Hyang and the studies it cites. No criticism from the 1920s and 30s is in the data.

평가의 주체는 후대 연구자입니다. 비평 진술은 UeDeKo 번역비평(필자 조향)과 그 안에 인용된 연구자들의 서술에서 나왔습니다. 1920~30년대 당시의 비평은 이 데이터에 없습니다.

Question 1 · Form · 질문 1

In what form did it appear?어떤 형태로 실렸나

Three of the five were serialised in newspapers or magazines. These serials are exactly where several UeDeKo records had to be merged into one work.

다섯 종 가운데 세 종이 신문·잡지 연재입니다. UeDeKo 레코드 여러 건이 한 작품으로 묶인 자리가 바로 이 연재들입니다.

Publication form, all 271 translations · 전체 271종의 게재 형태

Counted from the (description) sentence in each note. Because the same thing is always phrased the same way, a query can count the sentences.

메모의 (설명) 문장 “게재 형태는 …이다”를 그대로 세었습니다. 같은 뜻을 늘 같은 말로 적어 두었기 때문에 쿼리가 문장을 셀 수 있습니다.

The SPARQL behind this result · 이 결과를 낸 쿼리
PREFIX ktrans: <https://ktrans.aks.ac.kr/ontology#>
PREFIX kt:     <https://ktrans.aks.ac.kr/id/>
PREFIX lrmoo:  <http://iflastandards.info/ns/lrm/lrmoo/>
PREFIX crm:    <http://www.cidoc-crm.org/cidoc-crm/7.1.3/>
PREFIX skos:   <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs:   <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:    <http://www.w3.org/2001/XMLSchema#>

SELECT ?t ?year ?title ?translator ?note ?noteEn ?nomenNote
WHERE {
  ?t a ktrans:Translation ;
     rdfs:label ?title ;
     crm:P3_has_note ?note , ?noteEn ;
     crm:P4_has_time-span/crm:P82_at_some_time_within ?year .
  FILTER(lang(?note) = "ko" && lang(?noteEn) = "en")
  ?ev lrmoo:R17_created ?t ;
      crm:P14_carried_out_by/rdfs:label ?translator .
  FILTER(xsd:integer(STR(?year)) < 1946)
  BIND(CONCAT("kt:", STRAFTER(STR(?t), "/id/")) AS ?tid)
  ?nomen crm:P1_is_identified_by ?tid ;
         crm:P3_has_note ?nomenNote .
  FILTER(lang(?nomenNote) = "ko")
}
ORDER BY ?year ?t
PREFIX ktrans: <https://ktrans.aks.ac.kr/ontology#>
PREFIX kt:     <https://ktrans.aks.ac.kr/id/>
PREFIX lrmoo:  <http://iflastandards.info/ns/lrm/lrmoo/>
PREFIX crm:    <http://www.cidoc-crm.org/cidoc-crm/7.1.3/>
PREFIX skos:   <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs:   <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:    <http://www.w3.org/2001/XMLSchema#>

SELECT ?form (COUNT(?t) AS ?n) (MIN(?y) AS ?from) (MAX(?y) AS ?to)
WHERE {
  ?t a ktrans:Translation ;
     crm:P3_has_note ?note ;
     crm:P4_has_time-span/crm:P82_at_some_time_within ?y .
  FILTER(lang(?note) = "ko")
  BIND(STRBEFORE(STRAFTER(STR(?note), "게재 형태는 "), "이다") AS ?form)
}
GROUP BY ?form ORDER BY DESC(?n)
Question 2 · Route · 질문 2

Through which languages?무엇을 거쳐 옮겼나

All four translations with an identified source are relay translations; in 1923 a Japanese and a Chinese route existed side by side. Kim Yeong-jin's has no route information, so it stays 'not stated', not 'direct'.

저본이 밝혀진 네 종은 모두 중역입니다. 같은 1923년에 일본어와 중국어 두 경로가 함께 있었습니다. 김영진 역은 경유 정보가 없어서 ‘직접’이 아니라 ‘미기재’로 남겨 두었습니다.

Each route in the data. Open one to see its translation event (F28) as a picture and in TTL. 경로마다 데이터에 어떻게 적혀 있는지: 열면 번역 사건(F28)을 그림과 TTL로 봅니다.

The SPARQL behind this result · 이 결과를 낸 쿼리
PREFIX ktrans: <https://ktrans.aks.ac.kr/ontology#>
PREFIX kt:     <https://ktrans.aks.ac.kr/id/>
PREFIX lrmoo:  <http://iflastandards.info/ns/lrm/lrmoo/>
PREFIX crm:    <http://www.cidoc-crm.org/cidoc-crm/7.1.3/>
PREFIX skos:   <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs:   <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:    <http://www.w3.org/2001/XMLSchema#>

SELECT ?t ?via ?viaEn ?cert ?certEn ?source ?sourceEn ?evNote ?evNoteEn
WHERE {
  ?ev a lrmoo:F28_Expression_Creation ;
      lrmoo:R17_created ?t ;
      crm:P2_has_type ?v , ?c .
  ?v skos:inScheme kt:scheme-viaType ; rdfs:label ?via , ?viaEn .
  ?c skos:inScheme kt:scheme-certainty ; rdfs:label ?cert , ?certEn .
  FILTER(lang(?via) = "ko" && lang(?viaEn) = "en" && lang(?cert) = "ko" && lang(?certEn) = "en")
  OPTIONAL { ?ev crm:P3_has_note ?evNote , ?evNoteEn .
             FILTER(lang(?evNote) = "ko" && lang(?evNoteEn) = "en") }
  OPTIONAL { ?ev crm:P16_used_specific_object ?s .
             ?s rdfs:label ?source , ?sourceEn .
             FILTER(lang(?source) = "ko" && lang(?sourceEn) = "en") }
  ?t crm:P4_has_time-span/crm:P82_at_some_time_within ?y .
  FILTER(xsd:integer(STR(?y)) < 1946)
}
Question 3 · Evaluation · 질문 3

How do later scholars judge them?후대 연구자들은 어떻게 평가하나

Each cell is one translation meeting one dimension of the scheme. Evaluative dimensions show polarity (+ / − / 0), observational ones show the value. Click a cell or a heading to see the statements and their source paragraphs.

칸 하나가 번역 하나와 분류표 차원 하나가 만나는 자리입니다. 평가 항목에는 극성(+ / − / 0)이, 관찰 항목에는 값이 표시됩니다. 칸이나 머리글을 누르면 진술과 근거 문단이 아래에 나옵니다.

    The SPARQL behind this result · 이 결과를 낸 쿼리
    PREFIX ktrans: <https://ktrans.aks.ac.kr/ontology#>
PREFIX kt:     <https://ktrans.aks.ac.kr/id/>
PREFIX lrmoo:  <http://iflastandards.info/ns/lrm/lrmoo/>
PREFIX crm:    <http://www.cidoc-crm.org/cidoc-crm/7.1.3/>
PREFIX skos:   <http://www.w3.org/2004/02/skos/core#>
PREFIX rdfs:   <http://www.w3.org/2000/01/rdf-schema#>
PREFIX xsd:    <http://www.w3.org/2001/XMLSchema#>

SELECT ?cs ?t ?summary ?summaryEn ?critic ?stype ?stypeEn ?ftype ?ftypeEn
       ?dim ?dimEn ?val ?valEn ?pol ?para ?paraText ?note ?noteEn
WHERE {
  ?cs crm:P2_has_type kt:type-criticism ;
      crm:P140_assigned_attribute_to ?t ;
      rdfs:label ?summary , ?summaryEn ;
      crm:P14_carried_out_by/rdfs:label ?critic ;
      crm:P16_used_specific_object ?sp .
  ?sp crm:P1_is_identified_by ?para ;
      crm:P190_has_symbolic_content ?paraText .
  ?t a ktrans:Translation ;
     crm:P4_has_time-span/crm:P82_at_some_time_within ?y .
  FILTER(xsd:integer(STR(?y)) < 1946)
  FILTER(lang(?summary) = "ko" && lang(?summaryEn) = "en")
  ?cs crm:P2_has_type ?st . ?st skos:inScheme kt:scheme-statementType ; rdfs:label ?stype , ?stypeEn .
  FILTER(lang(?stype) = "ko" && lang(?stypeEn) = "en")
  OPTIONAL { ?cs crm:P2_has_type ?ft . ?ft skos:inScheme kt:scheme-factType ; rdfs:label ?ftype , ?ftypeEn .
             FILTER(lang(?ftype) = "ko" && lang(?ftypeEn) = "en") }
  OPTIONAL { ?cs crm:P177_assigned_property_of_type ?d . ?d rdfs:label ?dim , ?dimEn .
             FILTER(lang(?dim) = "ko" && lang(?dimEn) = "en") }
  OPTIONAL { ?cs crm:P141_assigned ?vv . ?vv rdfs:label ?val , ?valEn .
             FILTER(lang(?val) = "ko" && lang(?valEn) = "en") }
  OPTIONAL { ?cs ktrans:hasPolarity ?pol }
  OPTIONAL { ?cs crm:P3_has_note ?note , ?noteEn . FILTER(lang(?note) = "ko" && lang(?noteEn) = "en") }
}
    Question 4 · Asking in plain words · 질문 4

    A plain question, answered by an AI that queries the RDF평범한 말로 묻고, AI가 RDF로 답한다

    A person asks in plain words. The AI receives the RDF data, writes a SPARQL query itself, runs it on the data, and answers in plain words from the result alone. The four steps below record one real try on 19 October 2026. The table in step 3 is the same query, run again when this page was built.

    사람이 평범한 말로 묻습니다. AI는 RDF 데이터를 받아 SPARQL 쿼리를 직접 쓰고, 데이터에 돌린 뒤, 나온 결과만으로 평범한 말의 답을 씁니다. 아래 네 단계는 2026년 10월 19일에 실제로 한 번 해 본 기록입니다. 3단계의 표는 이 페이지를 만들 때 같은 쿼리를 다시 돌린 결과입니다.

    1. 1 · A person asks · 사람이 묻는다

    2. 2 · The AI receives the RDF · AI가 RDF를 받는다

      What it receives: the data and the schema, 12,199 triples. For example, the translation event (F28) of Kim Yeong-bo's 1923 translation, first as a picture, then as the TTL lines themselves. Each row is one triple: a node, a relation, and a node, a kind or a value.

      받은 것: ktrans-data.ttl과 ktrans-schema.ttl, 트리플 12,199개. 예를 들어 김영보 1923년 번역의 번역 사건(F28)을 먼저 그림으로, 이어서 데이터에 적힌 TTL 그대로 보여 줍니다. 한 줄이 트리플 하나입니다.

    3. 3 · The AI writes and runs a query · AI가 쿼리를 쓰고 돌린다
      The SPARQL the AI wrote · AI가 쓴 SPARQL
      # Question in plain words (asked on 19 October 2026):
#   Which Korean Werther translations were made through another language,
#   through which version, and who says so?
#   어떤 한국어 베르터 번역이 다른 언어를 거쳐 옮겨졌고, 무엇을 거쳤으며, 누가 그렇게 말했나요?
# The language model (Claude, configured model claude-opus-5-5) was given the RDF data (data/ktrans-data.ttl)
# and the schema, wrote this query, ran it on the data and answered from the rows.
# One question, one try: not yet a tested tool.
PREFIX lrmoo: <http://iflastandards.info/ns/lrm/lrmoo/>
PREFIX crm:   <http://www.cidoc-crm.org/cidoc-crm/7.1.3/>
PREFIX rdfs:  <http://www.w3.org/2000/01/rdf-schema#>
PREFIX kt:    <https://ktrans.aks.ac.kr/id/>

SELECT ?translation ?year ?source ?certainty ?note WHERE {
  ?event lrmoo:R17_created ?translation .
  ?event crm:P2_has_type kt:via-relay .
  ?event crm:P2_has_type ?certainty .
  FILTER(STRSTARTS(STR(?certainty), STR(kt:cert-)))
  OPTIONAL { ?event crm:P4_has_time-span/crm:P82_at_some_time_within ?year }
  OPTIONAL { ?event crm:P16_used_specific_object/rdfs:label ?source . FILTER(lang(?source) = "en") }
  OPTIONAL { ?event crm:P3_has_note ?note . FILTER(lang(?note) = "en") }
}
ORDER BY ?year

      rows · 줄

    4. 4 · The AI answers in plain words · AI가 평범한 말로 답한다

    Honest limit. One question, one try. The answer reads only the rows the query returned. Twelve later relay translations have no source on record, so they are not in it. A direction, not yet a tested tool.

    솔직한 한계. 질문 하나에 한 번 해 본 것입니다. 답은 쿼리가 돌려준 네 줄만 읽습니다. 이후의 중역 12종은 저본을 적은 기록 카드가 없어서 답에 나오지 않습니다. 검증된 도구가 아니라 방향입니다.

    Another way: giving the AI the results as text · 다른 방법: 쿼리 결과를 텍스트로 넘길 때

    The query results above, joined as text with their tags and paragraph numbers. The model's answer on the slides was written from this text.

    위 쿼리 결과들을 꼬리표 (설명)·(해석)·(편찬)·(근거)와 문단 번호와 함께 이어 붙인 텍스트입니다. 슬라이드의 '모델의 답'은 이 텍스트를 받은 모델의 답입니다.
